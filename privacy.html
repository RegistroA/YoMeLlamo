Política de privacidad de YoMeLlamo

YoMeLlamo utiliza servicios de Google mediante OAuth para crear y administrar formularios de Google Forms, leer las respuestas de los formularios y gestionar archivos relacionados con la aplicación en Google Drive.

Información utilizada

La aplicación puede procesar el correo electrónico asociado a la cuenta de Google utilizada para responder los formularios, así como las respuestas enviadas durante las rondas de votación.

Finalidad

Estos datos se utilizan exclusivamente para administrar las votaciones, contabilizar los resultados y evitar votos duplicados.

Uso de Google

YoMeLlamo utiliza Google Forms API y Google Drive API únicamente para las funciones necesarias para el funcionamiento de la plataforma.

Compartición de datos

La aplicación no vende información personal a terceros.

Contacto

Para consultas relacionadas con privacidad, contacte con el administrador de YoMeLlamo.
